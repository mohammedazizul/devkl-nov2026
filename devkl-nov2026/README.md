# Mizan — Ethical & Shariah-Compliant Financial Planning Welcome Page

A zero-dependency, fast-loading welcome web application designed specifically to solve **first-time visitor bounce** on financial websites.

## Problem Addressed

> *A person visits a financial website for the first time. They leave because they cannot quickly understand what it offers or whether it is relevant to them.*

## How This Welcome Page Solves It

1. **5-Second Clarity Hero ("What is this?")**
   - Explains **Mizan** in a single jargon-free sentence right above the fold alongside a visual **60-Second Overview** card showing the 3 buckets (*Rainy-Day Cash Shield*, *Life-Goal Halal Portfolios*, *Auto-Zakat & Cleansing*) and transparent `0.45% p.a.` fee.
2. **Part 1 — What Mizan Does (with Plain-English ↔ Shariah Structure Toggle)**
   - First-time visitors often bounce when confronted with terms like *Murabahah*, *Wakalah*, or *Sukuk*. Everything defaults to **Plain English**, with a one-click toggle for visitors who want to verify the formal Islamic finance structure.
3. **Part 2 — Who Mizan Helps (+ Radical Honesty)**
   - Concrete, relatable personas (*First-Time Earner*, *Busy Professional/Parent*, *Values-Driven Ethical Investor*) with one-click calculator presets, plus an explicit **"When Mizan is NOT for you"** callout (e.g., day-trading or crypto speculation) to build immediate trust.
4. **Part 3 — Interactive 30-Second Relevance Check & Halal Goal Simulator**
   - Visitors answer 3 quick taps (zero email gate) to get an honest fit verdict, then test starting amounts, monthly deposits, timelines, and `2.5%` Zakat nisab thresholds in real time.
5. **Part 4 — What the Visitor Can Do Next (3 Graduated Commitment Levels)**
   - **0 min / No Sign-Up:** Inspect an interactive sample dashboard modal right on the page.
   - **2 min / Save for Later:** View a 1-page Halal Money Starter Checklist.
   - **3 min / Ready to Start:** Walk through the exact 3 onboarding steps and save a personalized RM 50+ starter plan.

## Running Locally

Open `index.html` directly in any modern browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
